# RainBootFrontend
- Länk till den deployade sidan: http://178.62.234.61
- För att utföra betalningar via Stripe använder du testkortet med kortnummer 4242 4242 4242 4242, valfritt framtida datum och valfri CVC.
- Det här är frontendrepot för mitt projektarbete som är en webbshop där man kan köpa gummistövlar och paraplyer och betala via Stripe. Den är byggd med Angular för frontend och Java för backend.

# Följ dessa steg för att starta projektet lokalt
1. Säkerställ att du har backenden igång först. Du kan hitta backendrepot här: https://github.com/firpen/rain-boot-shop-backend
2. Säkerställ att du har Node.js och en kodeditor installerat.
3. Klona repot och spara det lokalt på din dator.
4. Öppna projektet i din IDE.
5. Kör kommandot "npm install" i din terminal för att installera alla dependencies för projektet.
6. Kör kommandot "npm start" i din terminal för att starta frontenden på http://localhost:4200/
