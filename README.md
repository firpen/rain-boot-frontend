# RainBootFrontend

This is the frontend repo to my webshop built with Angular for the frontend and Java for the backend.

# Follow these steps to start the frontend locally
1. Make sure you have the backend running first. You can find the backendrepo here: 
2. Make sure you have Node.js installed and a code editor of choice.
3. Clone the repo and save it locally on your computer.
4. Open the project in your IDE.
5. Run the command "npm install" in your terminal to install the dependencies for the project.
6. Run the command "npm start" in your terminal to start the frontend at http://localhost:4200/
